# Підсумковий проєкт: Інтернет-магазин «Комп'ютерна техніка» (варіант 27, Назарчук Богдан)

Папка: `final_nazarchuk/` (кладеться поруч з `config.php`, `db.php` та `lab*_nazarchuk`).
Усі файли мають префікс `nazarchuk_`, крім `index.php`; `config.php` і `db.php` беруться з папки на рівень вище.

| Файл                             | Призначення                                                                       |
| -------------------------------- | --------------------------------------------------------------------------------- |
| `index.php`                      | стартова сторінка (гість, 4 випадкові товари, 5 кнопок)                           |
| `nazarchuk_init.php`             | спільна ініціалізація: `config.php`, `db.php`, таблиці, початкові товари, функції |
| `nazarchuk_register.php`         | реєстрація з валідацією                                                           |
| `nazarchuk_login.php`            | вхід (логін, пароль, категорія)                                                   |
| `nazarchuk_forgot.php`           | нагадування пароля                                                                |
| `nazarchuk_users.php`            | усі користувачі (з паролями)                                                      |
| `nazarchuk_sklad.php`            | таблиця складу                                                                    |
| `nazarchuk_shop.php`             | каталог після входу (2 колонки)                                                   |
| `nazarchuk_product.php`          | товар: лічильник, «Додати в кошик» / «Поповнити склад»                            |
| `nazarchuk_cart.php`             | кошик покупця                                                                     |
| `nazarchuk_add.php`              | додати товар із завантаженням зображення (продавець)                              |
| `nazarchuk_audit.php`            | аудит складу (продавець)                                                          |
| `nazarchuk_logout.php`           | вихід                                                                             |
| `nazarchuk_style.css`, `images/` | стилі й зображення                                                                |

Таблиці `nazarchuk_storage`, `nazarchuk_users`, `nazarchuk_cart` створюються автоматично при першому відкритті будь-якої сторінки.
Домен e-mail змінюється в одному місці: константа `ALLOWED_DOMAIN` у `nazarchuk_init.php`.
